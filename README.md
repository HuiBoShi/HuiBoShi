## 当前重点课题

### 双面光伏三维自遮挡模型

正在构建面向真实几何场景的三维视角系数模型，用于量化：

- 地面阴影区与非阴影区对组件背面辐照度的独立贡献
- 组件、边框、扭矩管和支架结构造成的遮挡与可视性变化
- 背面辐照度沿组件表面的空间非均匀性
- 安装高度、倾角、行间距、太阳位置和地面反照率的影响
- 固定式与单轴跟踪式双面光伏系统的日、月和年尺度性能

模型采用地面与组件背面网格离散、单元间三维视角系数积分、遮挡判定和时变太阳几何计算，并计划通过解析极限、Radiance、bifacial_radiance 及实验数据进行交叉验证。

### 振动基底上的含颗粒液滴

研究垂直振动对含不溶性纳米颗粒液滴内部流动、动态润湿行为和近基底颗粒输运的影响，重点关注左右接触角不对称、周期性界面变形及颗粒富集机制。
